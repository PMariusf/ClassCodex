CLASS CODEX v0.2.0

INSTALL
Copy the ClassCodex folder into:
World of Warcraft/_retail_/Interface/AddOns/

Then start/restart WoW and type:
/codex

COMMANDS
/codex
/classcodex
/codex reset

V0.2
- Detects current class/spec.
- Detects active Hero Talent subtree ID and active talent config ID.
- Adds a Stats tab.
- Shows live Crit, Haste, Mastery and Versatility from the player.
- Includes Patch 12.1.5 general Subtlety stat guidance.
- Full demo content currently targets Rogue / Subtlety.
